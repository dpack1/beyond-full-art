Beyond Full Art

Choose a backup folder

Create a blank folder, then choose it here. The extension adds its own marker and a characters directory. If this browser already has art or notes, you can copy them into the folder. After the files check out, the copies in this browser can be removed, and new art and notes save in the folder.

Put that folder inside Google Drive for Desktop if you want Drive to sync it. On another computer, choose the same folder after it appears on disk.
