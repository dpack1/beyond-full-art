# Security

Beyond Full Art has no server. Character art, notes, and photos stay in the browser or in a folder the user chose.

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/dpack1/beyond-full-art/security/advisories/new). Do not open a public issue for a vulnerability or paste exploit details, session cookies, character files, or backup-folder contents into an issue.

A D&D Beyond page change that hides a button is a compatibility bug, not a security report. Those belong in a normal issue.
